KAMUS SEDERHANA - PRAKTIK 13 ANDROID

Fitur utama:
1. Tambah pasangan kata Indonesia dan Inggris.
2. Cari kata dari bahasa Indonesia.
3. Lihat seluruh daftar kata.
4. Data tersimpan secara lokal menggunakan Room Database.
5. Daftar diperbarui otomatis menggunakan Flow.

Latihan lanjutan dari materi juga sudah ditambahkan:
1. Hapus dengan geser: pada tab Daftar, geser item ke kiri atau kanan untuk menghapus kata dari database.
2. Pencarian langsung: pada tab Cari, hasil berubah saat teks diketik (TextWatcher), tanpa menekan tombol Cari.
3. Navigasi otomatis: BottomNavigationView terhubung ke Navigation Component melalui nav_graph.xml.

Cara membuka:
1. Ekstrak ZIP.
2. Buka Android Studio, pilih Open.
3. Pilih folder KamusSederhana hasil ekstrak (folder yang berisi settings.gradle.kts).
4. Tunggu Gradle Sync selesai.
5. Jalankan aplikasi.

Package: com.example.kamus
Minimum Android: Android 6.0 (API 23)
JDK/JVM: 17
